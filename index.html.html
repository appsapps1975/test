Developer & Admin Guide

How to Publish Website for Free & Set Up Free Grievance Backend

Step-by-step instructions to host this website on custom domains at zero cost and connect cloud databases.

1

How to Publish This Website for FREE

This website is built as a single, self-contained HTML file (`index.html`), making it exceptionally easy to host for free with zero server maintenance costs using platforms like GitHub Pages, Netlify, or Vercel.

GitHub Pages

  1. Create a free account on github.com.
  2. Create a new public repository (e.g., `karnal-councillor`).
  3. Upload or paste this `index.html` file into the repo root.
  4. Go to Settings > Pages, select `main` branch, and save. Your site is live!

Netlify Drop

  1. Save this code as `index.html` on your computer.
  2. Visit drop.netlify.com.
  3. Drag and drop your project folder or file into the browser.
  4. Netlify instantly deploys your site with a free `*.netlify.app` link!

Vercel

  1. Log into vercel.com with your GitHub account.
  2. Click Add New > Project and import your repository.
  3. Click Deploy. Vercel generates an instant HTTPS production URL.
2

How to Set Up a Free Grievance Portal Backend

Currently, this portal stores complaints in your browser session for instant demonstration. To connect a permanent, real-time, 100% free cloud database so citizens can submit complaints from any phone and your office staff can view them live, use Google Firebase Firestore:

Step-by-Step Firebase Integration:

  • Step 1: Go to Firebase Console (free Google account) and click Create Project.
  • Step 2: Enable Firestore Database in test mode and choose your closest server region (e.g., `asia-south1` for India).
  • Step 3: Register a web app in your Firebase project settings to get your unique `firebaseConfig` keys.
  • Step 4: In your JavaScript code, initialize Firebase and replace the local array push with `addDoc(collection(db, "artifacts", appId, "public", "data", "grievances"), formData)`.
  • Step 5: Use `onSnapshot()` to listen for real-time grievance updates so your municipal office dashboard auto-refreshes whenever a citizen submits a ticket!
3

Professional Recommendations for Political Portals

  • Custom Domain: Purchase an affordable domain name like `rajeshsharmakarnal.in` or `karnalcouncillor.in` (approx. ₹400-₹600/year) and link it to your GitHub/Netlify hosting.
  • WhatsApp Integration: Add a floating WhatsApp chat widget so citizens can directly message urgent civic issues with 1 click.
  • Bilingual Support: Add a Google Translate widget or Hindi language toggle to ensure maximum accessibility for Karnal residents.
